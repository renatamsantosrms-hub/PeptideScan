# PeptideScan
Pacote Python para análise e seleção de sequências peptídicas.

## Objetivo

Desenvolver uma ferramenta para analisar sequências
de aminoácidos e selecionar peptídeos com base em
propriedades físico-químicas e critérios definidos
pelo pesquisador.

## Funcionalidades previstas

- Leitura de arquivos FASTA.
- Cálculo do comprimento dos peptídeos.
- Cálculo da massa molecular.
- Análise da composição de aminoácidos.
- Filtragem por critérios combinados.
- Exportação dos resultados.

## Bibliotecas

- Pyteomics
- Pandas
- Pytest
